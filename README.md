# Water Tracker App <a name="about-project"></a>

Android water tracking application built with Kotlin and Jetpack Compose. The app demonstrates Android Activity Lifecycle management, SharedPreferences data persistence, lifecycle callback logging, and reactive UI updates. Users can track daily water intake, reset progress, and observe lifecycle events in real time through Logcat.

## 🛠️ Built With

- **Language:** Kotlin
- **UI Toolkit:** Jetpack Compose
- **Architecture:** Activity-Based Architecture
- **State Management:** Compose State (`mutableStateOf`)
- **Data Persistence:** SharedPreferences
- **Lifecycle Management:** Android Activity Lifecycle
- **Design System:** Material Design 3
- **Development Environment:** Android Studio
- **SDK:** Android SDK

---

### Key Features <a name="key-features"></a>

- ✅ Track daily water intake
- ✅ Add one glass of water at a time
- ✅ Reset water intake progress
- ✅ Save water intake using SharedPreferences
- ✅ Restore saved data when the app restarts
- ✅ Log all Activity Lifecycle callbacks
- ✅ Real-time lifecycle monitoring through Logcat
- ✅ Automatic UI updates with Compose recomposition
- ✅ Material Design 3 user interface
- ✅ Beginner-friendly lifecycle implementation

## 💻 Getting Started <a name="getting-started"></a>

To get a local copy up and running, follow these steps.

### Prerequisites

Before running this project, make sure you have:

- Android Studio installed
- Android SDK configured
- Kotlin support enabled
- Android Emulator or physical Android device
- JDK 11 or later

### Setup

Clone this repository:

```sh
git clone https://github.com/AbigiyaTY/WaterTracker.git
```

Navigate to the project directory:

```sh
cd WaterTracker
```

### Install

Open the project in Android Studio:

```sh
File → Open → Select Project Folder
```

Allow Android Studio to synchronize and download all required Gradle dependencies.

### Dependencies

The project uses Jetpack Compose and Material Design 3:

```kotlin
implementation("androidx.compose.material3:material3")
```

Sync the project after adding dependencies.

### Usage

This project demonstrates:

- Android Activity Lifecycle
- Jetpack Compose fundamentals
- SharedPreferences persistence
- State management with Compose
- Lifecycle callback logging
- Logcat monitoring
- Compose recomposition
- Material Design 3 components
- Saving and restoring application state
